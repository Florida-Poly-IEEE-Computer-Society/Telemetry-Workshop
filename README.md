# Telemetry Workshop

This workshop, we will show you how to build a working telemetry observation system built with FastAPI and React.

## Required Software

You will need the following packages/software in order to follow along for this workshop:

List of required software to partake in telemetry workshop.

### Required

- Python install for backend code: <https://www.python.org/downloads/>
- Node.js for frontend code: <https://nodejs.org/en/download>
- uv for easy python project management: <https://docs.astral.sh/uv/getting-started/installation/>
- git to fetch code locally: <https://git-scm.com/install/>

### Suggested

- VScode for text editing: <https://code.visualstudio.com/download>

## Getting Started

In order to follow this workshop, you will need to have this code installed locally. Run the following to clone this repository to your host machine:

```bash
git clone git@github.com:Florida-Poly-IEEE-Computer-Society/Telemetry-Workshop.git

# Enter telemetry workshop working directory
cd Telemetry-Workshop
```
